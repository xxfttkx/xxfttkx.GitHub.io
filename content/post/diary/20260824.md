```
cascade:
  - _target:
      path: /post/diary/** # 目标文件夹路径，支持通配符
    params:
      hidden: false # 为该文件夹下的所有内容设置 hidden: true
      hiddenInHome: true
      categories: ["diary"]
```

hidden是hugo或是stack theme自带的功能，hiddenInHome是自己之前加的，为的是能在archive中找到以及能在search中搜到:

```
   {{ $showDiary := .Site.Params.showDiary.default | default false }} 
    {{ $pages := where .Site.RegularPages "Section" "in" .Site.Params.mainSections }}
    {{ $notHidden := where $pages "Params.hidden" "!=" true }}
    {{ $notHiddenInHome := where $notHidden "Params.hiddenInHome" "!=" true }}
    
    {{ $filtered := $notHiddenInHome }}
```
